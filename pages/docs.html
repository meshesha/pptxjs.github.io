Documentation

PPTXjs v2 renders, presents, edits and exports PowerPoint (.pptx) files in the browser. It is written in TypeScript, has no jQuery and one runtime dependency (fflate). The renderer has no DOM dependency, so it also runs in Node.js and Web Workers.

Installation

npm install @meshesha/pptxjs

Without a bundler, use the single-file browser build. It exposes window.PPTXjs, registers the <pptx-viewer> and <pptx-editor> elements, and installs the jQuery plugin when jQuery is present.

<script src="https://unpkg.com/@meshesha/pptxjs/dist/pptxjs.umd.js"></script>

The styles are injected automatically. @meshesha/pptxjs/style.css is available if you prefer a static stylesheet.

Quick start

import { PptxViewer } from "@meshesha/pptxjs";

const viewer = new PptxViewer("#slides", { mode: "list", scale: "fit" });
viewer.on("load", ({ presentation }) => console.log(presentation.slides.length, "slides"));
viewer.on("error", ({ error }) => console.error(error.code, error.message));

await viewer.load("deck.pptx");      // URL, URL object, File, Blob, ArrayBuffer or Uint8Array

// a file chosen by the user
input.addEventListener("change", () => viewer.load(input.files[0]));

Styling

Slide styles are scoped to the viewer and isolated from common CSS resets (Bootstrap, Tailwind), so several viewers can share a page. Style the viewer interface with these classes: .pptxjs-toolbar, .pptxjs-btn, .pptxjs-counter, .pptxjs-progress-bar, .pptxjs-slide-wrap, plus the modes .pptxjs-mode-slideshow and .pptxjs-fullscreen. Each top-level shape is wrapped in [data-shape-id], which is handy for click handlers.

Editor UI

const editor = new PptxEditor("#editor", { fileName: "q3-review" });
await editor.load("deck.pptx");
editor.download("pptx");   // or "odp"

The toolbar provides undo/redo, adding text boxes, shapes and pictures, bold/italic/underline, size, colour, alignment, fill, arrange, duplicate and delete, and slide add/duplicate/move/hide/delete. A slide panel shows thumbnails. On the canvas: click to select, drag to move, use the handles to resize (Shift keeps the aspect ratio), and double-click to edit text. Shortcuts: Del, the arrow keys, Ctrl+Z/Y/D/B/I/U. Options: toolbar, thumbnails, readOnly, fileName, plus all viewer options.

Document API

PresentationDocument edits the real OOXML parts. Every call is one undoable step, it works without any UI (including in Node.js), and units are CSS pixels.

import { PresentationDocument, exportPptx } from "@meshesha/pptxjs";

const doc = await PresentationDocument.load(bytes);
const id = doc.addTextBox(0, { x: 80, y: 60, width: 400, height: 60 }, "Hello", { size: 32, bold: true });
doc.setShapeFill(0, id, "#FFE699");
doc.setShapeBounds(0, id, { x: 120 });
doc.duplicateSlide(0);
doc.undo();
const blob = exportPptx(doc);

Export .pptx / .odp

PPTX export is lossless: untouched parts (themes, charts, media, custom XML) are written back byte for byte, and media that is no longer used is removed. ODP export converts text (with fonts, colours and alignment), shapes (explicit geometry), pictures, tables, charts (as SVG), backgrounds, master decorations and speaker notes. Both have been checked in Microsoft PowerPoint.

import { exportPptx, exportOdp } from "@meshesha/pptxjs";
const pptx = exportPptx(docOrPackage);            // Blob
const odp = exportOdp(docOrPackage, { includeNotes: true });

ODP limitations: picture, gradient and pattern fills inside shapes become solid colours; WordArt effects, animations, video and editable charts are not converted.

Node.js & Web Workers

import { renderToHtml, renderToHtmlString } from "@meshesha/pptxjs";
import { readFile } from "node:fs/promises";

const { slides, css, width, height } = await renderToHtml(await readFile("deck.pptx"));
slides[0].html;    // HTML of slide 1
slides[0].notes;   // speaker notes

const fragment = await renderToHtmlString(await readFile("deck.pptx"));   // slides + CSS

In a Web Worker, call renderToHtml(bytes) and send the HTML strings to the page.

Right-to-left (Hebrew, Arabic…)

Paragraphs marked RTL in the file render right to left, with correct punctuation, RTL bullets and Hebrew numbering. For files without direction information, use textDirection: "auto" (detects Hebrew/Arabic from the text) or "rtl". On pages with dir="rtl" the interface is mirrored automatically; dir: "rtl" | "ltr" overrides it. Hebrew typed in the editor is saved as RTL, and ODP export keeps the direction. See the demo.

new PptxViewer("#slides", { textDirection: "auto", dir: "rtl" });

What is supported

  • Text: fonts, sizes, colours, bold, italic, underline, strike, caps, highlight, safe hyperlinks, bullets (characters, pictures, Symbol/Wingdings), all auto-numbering schemes, alignment, indents and RTL.
  • Shapes: 180+ preset shapes, custom geometry, rotation, flip, solid/gradient/pattern/picture fills, outlines, arrows, shadows (partial).
  • Pictures: PNG, JPEG, GIF, SVG, BMP, WebP and TIFF (browser dependent). EMF/WMF can't be displayed by browsers.
  • Tables with theme styles and merged cells; charts: bar/column, line, area, pie, doughnut, scatter and combos; SmartArt (drawn from its cached drawing).
  • Media: embedded video and audio; linked videos are opt-in.
  • Slides: backgrounds, layouts and masters, hidden slides, slide order, speaker notes and links between slides.
  • Browsers: current Chrome, Edge, Firefox and Safari; Node.js 18+. Internet Explorer is not supported (use v1).

Security

Presentations are untrusted input. PPTXjs escapes all document content when parsing, so files can't inject markup or script. It only allows safe link schemes (no javascript:), opens external links with rel="noopener", never embeds third-party pages unless you opt in (and then sandboxes them), rejects zip bombs, never touches global prototypes, and never loads scripts at runtime.

Errors

Errors are PptxError instances with a code: INVALID_FILE, LIMIT_EXCEEDED, FETCH_FAILED, RENDER_WARNING (non-fatal, through the warning event), EXPORT_FAILED or ABORTED. A slide that fails to render is replaced by a placeholder; the other slides still render.

Migrating from v1

Replace the nine v1 script tags (jQuery plugins, JSZip, FileReader, d3, nvd3, dingbat, divs2slides) and two stylesheets with one bundle. $(…).pptxToHtml() keeps working when jQuery is on the page.

<script src="jquery.min.js"></script>          <!-- only if your page uses jQuery -->
<script src="pptxjs.umd.js"></script>

Behaviour changes: slide order follows the presentation (not file names), text wraps at word boundaries, charts are SVG, keyboard shortcuts no longer capture keys page-wide, and errors are catchable. The full guide is in the repository.
