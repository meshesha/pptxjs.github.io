Live demos

Everything runs in your browser; files you open never leave your computer. Pick a demo, then open your own .pptx with the button below or by dropping it anywhere on the page.

Options

Keys: ← → Space Home End, F fullscreen, P play (click the slides first).

Events

    Click a shape to select it, drag to move, use the handles to resize, and double-click to edit text. Del deletes, the arrow keys nudge, Ctrl+Z / Ctrl+Y undo and redo. Download the result as .pptx or .odp from the toolbar.

    Convert

    The renderer needs no DOM, so the same code converts presentations in Web Workers and Node.js.

    import { renderToHtml, exportOdp, loadPptx } from "@meshesha/pptxjs";

const { slides, css } = await renderToHtml(file);
const odp = exportOdp(await loadPptx(file));   // Blob

    Slides & speaker notes

    1. Click “Download as HTML” to analyse the presentation.

    All slides

    <script src="pptxjs.umd.js"></script>
<div id="slides"></div>
<script>
  const viewer = new PPTXjs.PptxViewer("#slides");
  viewer.load("Sample_demo1.pptx");
</script>

    Slideshow

    new PPTXjs.PptxViewer("#slides", {
  mode: "slideshow",
  slideshow: { autoplay: 5, loop: true, transition: "fade" }
}).load("Sample_demo1.pptx");

    Open a local file

    const viewer = new PPTXjs.PptxViewer("#slides");
input.addEventListener("change", () => viewer.load(input.files[0]));

    Editor

    const editor = new PPTXjs.PptxEditor("#editor");
await editor.load("Sample_demo1.pptx");
editor.download("pptx");   // or "odp"

    Hebrew / Arabic without direction info

    new PPTXjs.PptxViewer("#slides", { textDirection: "auto" });
