PowerPoint in the browser.

Render, present, edit and export .pptx files with pure JavaScript. No server, no plugins, one small dependency.

Try the live demo Read the docs

Everything a presentation needs

PPTXjs reads the Office Open XML format directly: themes, layouts, masters, shapes, text, tables, charts and media.

Viewer and slideshow

Scrolling list or full slideshow with fit-to-screen scaling, keyboard control, fullscreen, autoplay and transitions.

Editor

Move, resize and restyle shapes, edit text inline, add pictures and shapes, manage slides. Full undo/redo.

Export .pptx and .odp

Lossless PowerPoint round trip: what you didn't change stays byte for byte. OpenDocument conversion included.

Charts without d3

Bar, line, area, pie, doughnut and scatter charts drawn as crisp, dependency-free SVG with theme colours.

Right-to-left

Hebrew, Arabic and Persian text with correct punctuation, RTL bullets and numbering, an RTL interface, and auto-detection.

Safe by design

Untrusted files can't inject script. Links are sanitised, zip bombs are rejected, and nothing global is touched.

Works with your stack

A plain class for any page, with first-class bindings for popular frameworks. It also runs in Node.js and Web Workers.
